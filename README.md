This project explores and analyzes airline data to uncover strategies for :

- increasing occupancy rates

- optimizing ticket pricing 

- improving profitability

Analysis Performed

- Identified aircraft with more than 100 seats.  
- Analyzed booking and revenue trends over time.  
- Compared fare types across aircraft (Business, Economy, Comfort).  
- Evaluated total revenue and occupancy per aircraft.  
- Simulated a 10% increase in occupancy to measure revenue growth.

 Tools
 - Python- Data analysis 
 - Pandas, NumPy- Data manipulation 
 - Matplotlib, Seaborn-Data visualization
